KasBeras KG — Versi Profesional

Perubahan dari KasBeras Pro:
- Semua fitur Rupiah/uang dihapus.
- Tidak ada saldo, pemasukan uang, pengeluaran uang, atau iuran.
- Semua perhitungan hanya menggunakan kilogram (Kg).
- Menu: Dashboard, Anggota, Beras Masuk, Pemakaian, Stok Beras, Laporan.
- Stok otomatis = total beras masuk - total pemakaian.
- Data tersimpan di localStorage browser.
- Login demo: admin / admin123.

Cara menjalankan:
1. Buka folder ini di VS Code.
2. Install extension Live Server.
3. Klik kanan index.html -> Open with Live Server.
4. Login menggunakan admin / admin123.
